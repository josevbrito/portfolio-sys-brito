## 🚀 About

This portfolio is more than a resume — it's a showcase of technical skills. Built with a custom **Terminal/Glassmorphism** design system, fully responsive, with bilingual support and integrated analytics.

### ✨ Key Features

* **Cyberpunk Aesthetic:** Neon Green/Deep Black visual identity via custom Tailwind CSS config.
* **Internationalization (i18n):** PT-BR and EN support via React Context API — no heavy external libraries.
* **Performance First:** Next.js App Router, Server Components, dynamic OG image, sitemap and robots.txt.
* **Interactive UI:** Smooth animations with Framer Motion.
* **Contact System:** Serverless form handling via Formspree.
* **Monitoring:** Vercel Analytics and Speed Insights for real-time performance tracking.

## 📂 Project Structure

```bash
portfolio-sys-brito/
├── app/
│   ├── components/    # Reusable UI components (Navbar, Footer)
│   ├── context/       # Global State (LanguageContext)
│   ├── data/          # Projects, timeline, and translations
│   ├── experience/    # Experience page
│   ├── projects/      # Project listing and dynamic detail pages
│   ├── utils/         # Utility functions
│   ├── layout.tsx     # Root layout & Analytics providers
│   └── page.tsx       # Homepage (Hero, Timeline, Contact)
└── public/            # Static assets (images, icons)
```
